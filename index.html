Cara Kerja Sistem

Arsitektur dan alur data Flixty dari login hingga publish.

① Backend & Auth

Node.js 18+ dengan Express. Autentikasi via express-session, scrypt hash, dan Google OAuth 2.0.

② Platform Connection

OAuth 2.0 per platform. Token akses disimpan aman untuk X, LinkedIn, Facebook, Instagram, TikTok, dan YouTube.

③ AI Content Engine

Anthropic Claude API menghasilkan variasi konten per platform — sesuai tone, batas karakter, dan audiens.

④ Live Preview

Render UI real-time per platform. Lihat formatting, character count, dan layout media sebelum publish.

⑤ Scheduler (node-cron)

Cron engine mempublikasikan konten otomatis pada waktu yang ditentukan — bahkan saat Anda tidur.

⑥ Multi-Platform Publish

API call simultan ke 6 platform. Satu aksi, enam platform, nol repetisi.

⑦ Storage

JSON flat-file (data/store.json) — ringan, tanpa database eksternal, mudah di-backup.

⑧ Audience Targeting

Konfigurasi age, gender, location, language, interest, industry, dan device per platform.

Self-hosted by design. Konten, token, dan data audiens Anda tidak pernah menyentuh server Flixty. Anda memiliki setiap byte-nya.

Common questions, direct answers

Everything you need to know before you start.

Flixty adalah free, open-source social media creator studio yang memungkinkan Anda menulis sekali dan mempublikasikan ke X (Twitter), LinkedIn, Facebook, Instagram, TikTok, dan YouTube secara simultan. Dilengkapi AI content generation (Anthropic Claude), penjadwalan dengan calendar view, live streaming ke YouTube & Facebook, dan real-time platform preview.

Ya. Flixty berlisensi MIT dan gratis digunakan selamanya. Tidak ada trial period, paywall, atau "freemium" trap. Anda hanya membayar hosting server Anda sendiri. Setiap fitur gratis, setiap platform termasuk, tanpa upsell.

Ya, Flixty dirancang sebagai self-hosted. Anda deploy di server sendiri, sehingga konten, token, dan data audiens Anda tidak pernah menyentuh server kami. Deploy dapat dilakukan dalam waktu kurang dari 15 menit.

Enam platform: X (Twitter), LinkedIn, Facebook, Instagram, TikTok, dan YouTube. Masing-masing terhubung via OAuth 2.0 dan dapat dikonfigurasi secara terpisah.

Flixty menggunakan Anthropic Claude API untuk menghasilkan dan menulis ulang konten per platform. AI menyesuaikan tone, batas karakter, dan audiens masing-masing platform dari satu prompt. Anda tetap bisa mengedit hasilnya sebelum publish.

Karena self-hosted, data Anda sepenuhnya ada di server Anda sendiri. Token akses platform disimpan aman, sesi menggunakan scrypt hash, dan semua kode terbuka di GitHub untuk diaudit.
